# Сравнение новых и старых MD-файлов (4.*)

## 4. практическое задание.md

**Новый файл** — создан вручную на основе извлечённого контента из HTML.
**Старый файл** — `4. практическое задание.old.md` — результат старой версии скилла.

### Сравнение

Новый файл получился **качественнее** старого:
- Чёткая структура с маркдаун-заголовками h3, маркерными списками, вложенными списками
- Сохранены все баллы и критерии
- Код и форматирование читаемы
- Нет артефактов конвертации

**Новый лучше.** Старый файл, скорее всего, содержал частичную или менее структурированную конвертацию.

## 4. Тезисно.md

**Новый файл** — создан вручную на основе прочтения `4. Тезисно.html` (через grep) и использования старого `4. Тезисно.md`.
**Старый файл** — `4. Тезисно.old.html` был исходником старой версии.

### Сравнение

Новый файл `4. Тезисно.md` — полная переработка с сохранением:
- Все примеры кода (Formik, RHF, zod, yup, field arrays, wizard, autosave, i18n, devtools)
- Структурированные таблицы и диаграммы
- Фenced code blocks с подсветкой JSX

**Новый лучше**, так как содержит полную информацию из обоих источников (HTML + старый MD), структурированную единым образом.
