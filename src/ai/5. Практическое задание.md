# Практическое задание — useRef

## Цель

- Закрепить навык использования `useRef` в React для хранения данных между рендерами и работы с DOM-элементами без ререндера.
- Научиться реализовывать счетчики, сохранение предыдущих значений и фокусировку на элементах без использования состояния.

## Структура проекта

```
src/
└── features/
    └── refExamples/
        ├── ClickTimer.tsx
        ├── PreviousInput.tsx
        ├── FocusTracker.tsx
        └── DebouncedLogger.tsx
```

## Общие рекомендации

- Не используйте `useState`, если это не требуется.
- Все временные значения и счетчики храните через `useRef`.
- Проверяйте, что компоненты не перерисовываются при обновлении `ref`.

---

## Основная часть (до 9 баллов)

### 1. Компонент ClickTimer (3 балла)

Создайте компонент `ClickTimer`, в котором:

- Время первого клика сохраняется через `useRef<Date | null>(null)`.
- Время последнего клика сохраняется через `useRef<Date | null>(null)`.
- Отображается количество кликов и время.
- **Важно:** компоненты не должны перерисовываться при обновлении `ref` (перерисовка только по клику, через `key`).
- Время первого/последнего клика и счётчик кликов — через `useRef`, НЕ через `useState`.

### 2. PreviousInput (3 балла)

Компонент, в котором:

- Есть поле ввода (`<input>`).
- Предыдущее значение хранится через `useRef<string>`.
- При вводе отображается предыдущее значение.
- Текущее значение можно хранить через `useState` (оно влияет на UI).
- **Проверить:** при обновлении `ref.current` (предыдущее значение) компонент НЕ перерисовывается.

### 3. FocusTracker (3 балла)

Компонент, в котором:

- Есть кнопка и поле ввода (`<input>`).
- При нажатии на кнопку фокус переносится в поле ввода (прямой DOM-доступ через `ref`).
- Используется `useRef<HTMLInputElement>` для ссылки на DOM-элемент.
- Вызывается `ref.current?.focus()` для фокусировки.

### 4. DebouncedLogger (3 балла)

Компонент, в котором:

- Есть поле ввода, значение логируется в консоль с задержкой 1 секунду.
- Таймер debounce хранится через `useRef<ReturnType<typeof setTimeout> | null>(null)`.
- При каждом вводе предыдущий таймер очищается и создаётся новый.
- **Важно:** не использовать `useState` для таймера — только `useRef`.
- Используй `useEffect` для подписки на изменения значения.

---

## Ключевые требования к useRef (сводка)

### Общие правила из задания:

- ❌ Не используй `useState`, если это не требуется (для таймеров, предыдущих значений, DOM-ссылок — только `useRef`)
- ✅ Все временные значения и счетчики храните через `useRef`
- ✅ Проверяй, что компоненты не перерисовываются при обновлении `ref` (перерисовка только по клику/вводу)
- ✅ `ref.current` — прямой доступ к DOM-элементам

### Примеры паттернов:

```tsx
// Сохранение значения между рендерами
const clickCountRef = useRef<number>(0);

// Ссылка на DOM-элемент
const inputRef = useRef<HTMLInputElement>(null);
inputRef.current?.focus();

// Debounce с useRef
const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

useEffect(() => {
  if (timerRef.current) clearTimeout(timerRef.current);
  timerRef.current = setTimeout(() => console.log(value), 1000);
  return () => { if (timerRef.current) clearTimeout(timerRef.current); };
}, [value]);
```
